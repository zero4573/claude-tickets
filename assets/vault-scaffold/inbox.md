# Inbox

Open tasks in `inbox/`: the follow-up notes unattended commands leave for you
(`type: follow-ups`) and any other draft with tasks. Tick them off; delete a note when it is
done. A ticket's tasks are in its `tickets/<source>/<ID>/<ID>-status.md`.

```tasks
not done
path regex matches /^inbox\//
group by filename
sort by created
```
